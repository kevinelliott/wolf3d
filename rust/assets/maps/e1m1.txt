# Wolfenstein-Rust level format.
#
# One char per cell. Comments start with #. Leading/trailing whitespace
# is stripped. Recognized tokens:
#   .  empty floor
#   1..9  wall texture id (indices into Atlas::walls)
#   @  closed sliding door
#   P  player spawn (one per map)
#   G  guard
#   a  ammo pickup
#   m  medkit
#   b  barrel (decoration)
#   l  lamp (decoration)
#
# (The current build hard-codes the layout in map::Map::sample(); this
# file is the canonical reference for the text format and is parsed by
# Map::from_rows when level loading is wired up.)
